## 🛠 Installation

### Step 1 – Clone repo

```bash
git clone https://github.com/TermuxT00LsByAnonymous/SIMDatabaseBot.git
```

### Step 2 – Open folder

```bash
cd SimDatabaseBot
```

### Step 3 – Install requirements

```bash
pip install -r requirements.txt
```

### Step 4 – Configure bot

Edit config:

```python
BOT_TOKEN = "YOUR_TOKEN"
ADMIN_ID = YOUR_ID
CHANNEL_1 = "@CHANNEL"
CHANNEL_2 = "@CHANNEL"
API_URL = "API_LINK"
```

### Step 5 – Run bot

```bash
python SimDataBase.py
```
